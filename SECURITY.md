# Security policy

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could put payments, order
data, or infrastructure at risk.

Use GitHub's private vulnerability reporting form for this repository:

https://github.com/juangh123/ArcProof/security/advisories/new

Include the affected endpoint or commit, reproduction steps, and the expected
impact. Never include private keys, API keys, wallet seed phrases, or full
supplier documents in a report.

## Supported version

Security fixes are applied to the latest commit on `master` and the latest
tagged release.
